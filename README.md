# tviyoberigkr-lab.github.io

Головна адреса GitHub Pages для проєктів CoLaba Production.

- `index.html` — переадресація на Syto: https://tviyoberigkr-lab.github.io/syto/
- `.well-known/assetlinks.json` — підтвердження для Google, що застосунок Syto для Android і сайт мають одного власника
  (Digital Asset Links; без нього застосунок показує смужку з адресою сайту).
- `.nojekyll` — щоб GitHub Pages публікував папку `.well-known` (Jekyll за замовчуванням ховає теки з крапкою).
